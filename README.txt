КАК МЕНЯТЬ РЕЗУЛЬТАТЫ

Открой data/state.json.

ROUND ROBIN:
Внутри matches есть группы A, B, C, D.
Каждая группа содержит 3 матча.

Пример:
{
  "p1": "Игрок 1",
  "p2": "Игрок 2",
  "s1": "2",
  "s2": "1"
}

Меняй только s1 и s2.
Если матч ещё не сыгран — оставляй "".

После изменения:
1. Commit changes в GitHub.
2. Render автоматически сделает новый deploy.
3. После завершения deploy участники увидят новые данные.

PLAY-OFF:
Плей-офф автоматически строится после завершения всех 12 матчей Round Robin.
Посев:
QF1 = A1 vs B2
QF2 = B1 vs A2
QF3 = C1 vs D2
QF4 = D1 vs C2

Счёт плей-офф хранится в playoffs в state.json. Если нужно вручную менять уже сформированный плей-офф, сначала открой сайт после завершения группового этапа, посмотри текущие ID матчей (qf1, qf2, qf3, qf4, sf1, sf2, uf, lb1, lb2, lb3, lb4, lb5, lbf, gf), затем внеси s1/s2 для нужного ID.

ВАЖНО:
Не меняй названия p1/p2 в matches без необходимости — по ним сайт связывает матч с игроками.
Счёт должен быть разным, например 2:1. Ничья не считается завершённым матчем.
